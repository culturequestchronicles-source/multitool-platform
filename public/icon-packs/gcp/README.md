# Google Cloud Icon Pack (Local)

Drop official Google Cloud architecture icons (SVG/PNG) into `public/icon-packs/gcp/icons/` and map them in `public/icon-packs/gcp/manifest.json`.

The editor loads:

`/icon-packs/gcp/manifest.json`

This repo includes a small curated subset under `public/icon-packs/gcp/icons/` (currently category icons). Add service-specific icons and update the manifest as needed.

Use `public/icon-packs/aws/README.md` as the detailed reference for the manifest format and available keys.
