# Azure Icon Pack (Local)

Drop official Azure architecture icons (SVG/PNG) into `public/icon-packs/azure/icons/` and map them in `public/icon-packs/azure/manifest.json`.

The editor loads:

`/icon-packs/azure/manifest.json`

This repo includes a small curated subset under `public/icon-packs/azure/icons/`. Add more icons and update the manifest as needed.

Use `public/icon-packs/aws/README.md` as the detailed reference for the manifest format and available keys.
